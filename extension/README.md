# SPARK Companion — Intent Before Action

Optional browser-extension prototype for The Spark Between Us.

It stores a person's purpose, values to protect, and selected consequential actions locally. Before matching send, publish, buy, or delete controls continue, the extension returns that intent to the person and offers three real choices: continue, revise, or stop.

This is an add-on—not the center of SPARK. SPARK itself is a human sharing system for turning sparks into shared learning, capability, contribution, and returned value.

## Load in Chrome

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked**.
4. Select this `extension` folder.

The prototype uses local browser storage and requires no account or external service.
